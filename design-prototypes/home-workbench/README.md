# 首页工作台交互原型

独立前端评审原型，不连接正式数据库或 API。预览：http://127.0.0.1:4180/ 。正式首页已接入系统，原型保留为交互和样式参考。

## 可点击流程

- 个人工作项按日期分组，参与项目可单独查看，无工作项项目有空状态。
- 工作项详情：提交与反馈、计划工时、执行人交接。
- 新增提交：设计多链接、文案正文、自动版本号；文字反馈与调整项、源文件链接及最终版。
- 近期里程碑列表及详情。
- 工时快捷带入项目、添加/编辑/删除、首页汇总同步。
- 日历月/周/日/列表、日期导航、空白日期或时间添加记录、点击记录编辑。
- 全部功能搜索；非首页模块为入口预览。

## 数据边界

示例人员小花，演示日期固定2026-09-10。所有修改只保存在页面内存，刷新或重置恢复。工时只关联项目。链接为 example.com 示例，非实际设计文件。

反馈编辑简化为文字和逐行调整项；正式接入应复用已有图片、反馈和版本组件。计划工时和交接标签为只读内容预览。

## 运行

在本目录执行 `npm install`、`npm run dev -- --host 127.0.0.1 --port 4180 --strictPort`。构建：`npm run build`。

正式首页实现位于仓库根目录的 `src/app/page.tsx`；原型仅使用示例数据。
